# Roteiro de validação — Aula 09 + três bônus

Marcar apenas após execução real no Expo Go/Android ou emulador. Os testes Node não substituem estes cenários.

- [ ] 01. Abrir sem dados: ícone e orientação de lista vazia.
- [ ] 02. Salvar com campos vazios: erro por campo; não salva.
- [ ] 03. Descrição ab, valor 0 e data futura: mensagens específicas.
- [ ] 04. Corrigir apenas descrição: some somente o erro dela.
- [ ] 05. Teclado aberto: Salvar continua acessível.
- [ ] 06. Criar despesa válida: aparece em Todas e Recentes; soma atualizada.
- [ ] 07. Tocar no item: formulário preenchido e título Editar despesa.
- [ ] 08. Alterar valor: atualiza sem duplicar; abas consistentes.
- [ ] 09. Cancelar excluir preserva; confirmar remove.
- [ ] 10. Fechar e reabrir: despesas mantidas no AsyncStorage.
- [ ] 11. Buscar ALM: resultados/quantidade/total corretos.
- [ ] 12. Busca inexistente: estado vazio.
- [ ] 13. Mudar tema do sistema: pelo menos duas telas se adaptam.
- [ ] 14. Cards com sombra; sem avisos de key nem erros no console.
- [ ] Bônus filtro: chips de categoria combinados à busca.
- [ ] Bônus limpeza: cancelar preserva; confirmar limpa e persiste.
- [ ] Bônus responsivo: largura 600 uma coluna, 601 duas.
- [ ] Testar DateTimePicker, Alert e Modal no Android/Expo Go.
- [ ] Tirar prints da lista clara/escura e formulário com mensagens de erro.
